# Prompt สำเร็จรูป — คัดลอกไปวางได้เลย

## ⭐ ตัวหลัก: ตรวจทั้ง 2085 ข้อรวดเดียว

```
/audit-v4 ตรวจทั้ง 2085 ข้อของ V4 อย่างละเอียด ตั้งแต่ข้อ 1 ถึง 2085

เงื่อนไข:
1. ข้อไหนมี exhibit ให้เปิดรูปดูจริงทุกข้อ ห้ามเชื่อคำอธิบายเดิมหรือข้อความสรุปในโจทย์ รูปเล็กให้ขยายด้วย zoom.py ก่อนอ่าน
2. คิดคำตอบเองตามหลัก CCNA 200-301 ก่อน แล้วค่อยเทียบกับเฉลยในระบบ
3. เจอผิดให้แก้ทันที พร้อมใส่บรรทัด ⚠️ หมายเหตุ (แก้เฉลย) และแก้สำเนาในคลัง V1/V2/V3 ที่เป็นข้อเดียวกันไปพร้อมกัน
4. จดลง CCNA_V4_FULLCHECK_2085.md ทุก 100 ข้อระหว่างทาง ไม่ใช่จดตอนจบ
5. ทำต่อเนื่องไปเรื่อยๆ ไม่ต้องหยุดถามระหว่างทาง ยกเว้นเจอข้อที่ต้องให้ฉันตัดสินใจจริงๆ
6. จบแล้วรัน tsc + build + audit.cjs + xcheck.cjs แล้วสรุปผล

ถ้า context ใกล้เต็ม ให้จดความคืบหน้าลงไฟล์ md ให้ครบก่อน แล้วบอกฉันว่าค้างที่ข้อไหน
```

## ทำต่อจากที่ค้าง (ใช้เปิดเซสชันถัดไป)

```
/audit-v4 ทำต่อจากที่ค้างไว้ใน CCNA_V4_FULLCHECK_2085.md ใช้เงื่อนไขเดิมทุกข้อ เปิดรูปทุก exhibit จดทุก 100 ข้อ ทำจนจบ 2085
```

## เจาะเฉพาะข้อที่มีรูป (979 ข้อ — คุ้มที่สุดถ้าเวลาจำกัด)

จุดที่ error ซ่อนอยู่คือรูป ไม่ใช่ข้อความ ถ้าอยากได้ผลเร็วให้ไล่เฉพาะกลุ่มนี้

```
/audit-v4 ไล่เฉพาะข้อที่มี image ทั้ง 979 ข้อ เปิดรูปทุกข้อ ห้ามเชื่อคำอธิบายเดิม เจอผิดแก้ทันทีพร้อมสำเนาในคลังอื่น จดทุก 100 ข้อ
```

## หมายเหตุตามจริง

2085 ข้อ + เปิดรูป 979 ใบ **จบในเซสชันเดียวไม่ได้** — prompt ตัวหลักจึงสั่งให้จดลง
`CCNA_V4_FULLCHECK_2085.md` ระหว่างทาง เพื่อให้เซสชันถัดไปเปิดมาแล้วทำต่อได้ทันที
คาดว่าใช้ประมาณ 3–5 รอบ

ถ้าอยากได้ผลลัพธ์เร็วที่สุดต่อ token ที่ใช้ ให้เริ่มจาก **prompt "เจาะเฉพาะข้อที่มีรูป"**
เพราะข้อผิดทั้งหมดที่เจอในรอบแรก (#1508, #1728, #1680) มาจาก exhibit ทั้งสิ้น
ส่วนข้อที่เป็นข้อความล้วนผ่านการตรวจมาแล้วครบ
